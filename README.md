
  # Dynamic Recommendation Page Prototypes

  This is a code bundle for Dynamic Recommendation Page Prototypes. The original project is available at https://www.figma.com/design/9Fucu5GP7mc1MOqv4F7JzX/Dynamic-Recommendation-Page-Prototypes.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploy (Vercel — public)

  If org GitHub Pages is restricted, use [Vercel](https://vercel.com) (free hobby tier):

  1. Sign in at [vercel.com](https://vercel.com) with GitHub.
  2. **Add New Project** → import `EdisonInternational/obi-experimental`.
  3. Leave defaults: **Framework** Vite, **Build** `npm run build`, **Output** `dist`.
  4. Deploy. Your app will be at `https://<project>.vercel.app` (no `/obi-experimental/` prefix).

  Or from this folder: `npx vercel` then `npx vercel --prod`.

  GitHub Pages (if enabled later): `https://edisoninternational.github.io/obi-experimental/`
